# Ashik Bro — Developer Portfolio

This repository contains the source for a GitHub Pages portfolio highlighting
projects, technical skills, achievements, and contact information.

## Local preview

The site is built with GitHub Pages and Jekyll:

```bash
bundle install
bundle exec jekyll serve
```

Open `http://localhost:4000` after the server starts.

## Publishing

Push changes to `main`. The workflow in
`.github/workflows/jekyll-gh-pages.yml` builds the site and deploys it to
GitHub Pages.

## Customization

Update `index.md` as projects evolve. Keep project links, dates, maturity
claims, and technology descriptions accurate and use accessible headings and
link text.

## Structure

```text
index.md                              Portfolio landing page
.github/workflows/jekyll-gh-pages.yml GitHub Pages deployment
```
